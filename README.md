# 📊 Stock App Visualizer

A simple web-based visualization tool to view and compare various stock/index attributes from a CSV file. Built using HTML, CSS, JavaScript, and Chart.js for interactive data representation. Includes dynamic company filtering and a clean UI.

---

## 🚀 Features

- 📈 Horizontal bar chart visualization of stock/index attributes
- 🔍 Real-time search filter for companies
- 🧭 Interactive and user-friendly layout

---

## 🧰 Technologies Used

- HTML5 & CSS3
- Vanilla JavaScript
- Chart.js

---

## ⚙️ How to Run Locally

> **Recommended**: Use [Live Server Extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) in Visual Studio Code.

### 📌 Steps

1. **Clone the repository**

```bash
git clone https://github.com/stanishq2710/stock_app_test.git
cd stock_app_test
code .
```

2. **Use Live Server**

Make sure the Live Server extension is installed.

Right-click `index.html` and click **"Open with Live Server"**.

3. **Access the app in your browser**

It will open at something like:

`http://127.0.0.1:5500/index.html`
